# Security policy

## Supported versions

Security fixes are made on the latest `main` branch. There are no supported
stable releases yet.

## Reporting a vulnerability

Please use GitHub's private **Report a vulnerability** form in the repository's
Security tab. Do not open a public issue for an unpatched vulnerability. Include
the affected commit, reproduction steps, impact, and any suggested mitigation.

Maintainers will aim to acknowledge a report within 72 hours, provide a status
update within seven days, and coordinate disclosure after a fix is available.
These are response targets, not a bug-bounty promise.

For ordinary bugs with no security impact, use the public issue tracker.

Never include API tokens, player data, private room links, or other people's
personal information in a report.
